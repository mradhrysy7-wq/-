# على مهل — مساحة صغيرة ليوم أهدأ

تطبيق ويب مبني باستخدام **React 19** و**TypeScript** و**Vite**، يعيد تقديم منصة «على مهل» المتخصصة في أفكار تنظيم الحياة والروتين اليومي والعادات الهادئة بدون ضغط الكمال.

## المميزات الأساسية
- **تصميم هادئ ومريح للعين**: ألوان ترابية وطبيعية تدعم الوضع الفاتح والوضع الداكن (Dark / Light Theme) مع حفظ التفضيل محلياً.
- **عادات يومية تفاعلية**: ميزة «عادة اليوم» التفاعلية التي تتيح تسجيل إنجاز العادة وحفظ الحالة لليوم في المتصفح.
- **دليل المقالات الـ 9 الكامل**:
  1. إغلاق هادئ لليوم: روتين من عشر دقائق (روتين مسائي)
  2. ترتيب المكتب في ربع ساعة، بلا مشتريات (مساحة العمل)
  3. خطّط أسبوعك بثلاثة أسئلة فقط (تخطيط مرن)
  4. استعد لصباح أهدأ في خمس دقائق (بداية اليوم)
  5. مدخل البيت: ترتيب صغير يسهّل الخروج (ترتيب البيت)
  6. استراحة قصيرة بين مهمتين، على طريقتك (مساحة بين المهام)
  7. رتّب درجًا واحدًا من دون قلب البيت (ترتيب البيت)
  8. قائمة مشتريات مرنة تبدأ من مطبخك (تخطيط البيت)
  9. نظّم شاشة هاتفك بخطوات صغيرة (مساحة رقمية)
- **رسومات تجريدية فنية بـ CSS خالص**: تمثيل بصري فريد لكل مقال وللهيدر وعادة اليوم دون الحاجة لملفات صور ثقيلة.
- **صفحات معلوماتية مخصصة**: صفحة "من نحن" (عن الموقع)، "سياسة الخصوصية"، و"تواصل".
- **توافق كامل مع اللغة العربية واتجاه RTL**.

## التطوير والتشغيل
```bash
npm install
npm run dev
```
يعمل خادم التطوير على المنفذ `3000`.
